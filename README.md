# zune30-research
面向 Zune 30G 的中、日、韩文字显示与个性化研究项目，支持将 1.0 TEST 设备重新升级至微软官方 3.3 系统，并实现持久中文显示、标准 MTP 拖放传歌和原生 FLAC 播放。  A CJK text display and customization project for the Zune 30G. Upgrade devices running 1.0 TEST firmware to Microsoft’s official 3.3 firmware, with persistent Chinese text support, standard MTP drag-and-drop music transfers, and native FLAC playback.
